# One comment line per edit with your name, then one line per colour or per block id:
#
# Name: what the edit adds
# colour: modid:block modid:block:meta modid:block:state=value
# block.<id>: modid:block
#
# Colours: white, weak white, orange, yellow, lime, green, cyan, light blue, blue,
# purple, magenta, pink, red, brown
# Emissive highlights: low white, medium red/orange, high blue/purple
# A block.<id> line uses that exact Eclipse id, for blocks that look better on a
# specific id than on the default one for their colour.
